    Version 3.2

    Your prompts, finally in one place.

    Save the prompts that actually work, find them in a keystroke, turn them into reusable templates — all stored privately in this browser. No account, no server, no tracking.

    • Search that finds things

      One box searches titles, prompt text, categories and tags, then ranks the best matches first.

    • Filters that stack

      Combine search with a category, several tags and favourites — then reset it all with one click.

    • Templates with variables

      Write {{topic}} once, fill it in before copying, and reuse the same prompt forever.

    • Your data stays yours

      Everything lives in this browser — no account, no server, no tracking. Nothing is sent anywhere.

    • Every edit is remembered

      Open the History tab to compare versions and bring an old one back without losing the current text.

    • Backups you can trust

      Full checksummed backups, a preview before any import, and a safety copy so an import can be undone.

    • Works offline

      Install it as an app, or just keep the tab: after the first visit it opens with no connection.

    Press CtrlK to jump to any prompt, ? for all shortcuts.

        Privacy
        
      
          
        
        • Your prompts and their history are stored only in this browser. They are never uploaded.
          • 
        
        • There is no account, no analytics and no tracking. The app makes no network requests of its own.
          • 
        
        • Stored data is not encrypted: anyone who can use this browser profile can read it. Encryption is on the roadmap but is not built yet.
          • 
        
        • Clearing site data in your browser deletes your library. Create a backup first.

    Your prompts, finally in one place.

    Save the prompts that actually work, find them in a keystroke, turn them into reusable templates — all stored privately in this browser. No account, no server, no tracking.

    • Search that finds things

      One box searches titles, prompt text, categories and tags, then ranks the best matches first.

    • Filters that stack

      Combine search with a category, several tags and favourites — then reset it all with one click.

    • Templates with variables

      Write {{topic}} once, fill it in before copying, and reuse the same prompt forever.

    • Your data stays yours

      Everything lives in this browser. Export to JSON or Markdown whenever you want a backup.
